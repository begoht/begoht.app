COMMENT ÇA MARCHE

Demander un voyage est très simple.

Chaque étape est pensée pour confirmer le prix, le trajet et le chauffeur avant le départ.

01
ETAPE 01

Sélectionner votre destination

Indiquez où vous voulez aller. L'application trace le trajet et affiche le prix estimé avant la confirmation.

02
ETAPE 02

Choisir le mode de paiement

Choisissez le mode de paiement que vous souhaitez utiliser pour votre voyage, selon les options disponibles dans l'application.

03
ETAPE 03

Demander votre voyage

Lancez la demande et attendez qu'un chauffeur disponible accepte votre trajet.

04
ETAPE 04
