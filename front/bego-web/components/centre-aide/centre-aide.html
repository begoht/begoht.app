QUESTIONS FRÉQUENTES

Les réponses aux questions les plus courantes.

Ouvre l'application BeGO, indique ta destination, vérifie les informations du voyage puis confirme ta demande.

Les modes de paiement disponibles sont affichés directement dans l'application lors de la demande de votre voyage.

Accède à ton profil depuis l'application BeGO puis ouvre les paramètres de ton compte.

Si tu rencontres un problème, utilise les options d'aide disponibles dans l'application ou contacte directement le support BeGO.

Consulte la section Motoristes pour découvrir les conditions, les documents nécessaires et les étapes d'inscription.

Vérifie ta connexion internet, redémarre l'application et assure-toi d'utiliser la dernière version disponible.
